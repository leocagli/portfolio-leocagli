# Models

`runa-heroe.min.glb` is a compressed copy of the Runa hero Tripo model published at:

https://playruna.vercel.app/jugar/assets/tripo/heroe.glb

The source file and the Runa repository were not modified. This copy is unlit, with 256px JPEG textures, no Draco/Meshopt, and no required glTF extensions, so the page does not need an extra decoder.
